A Transformer-Based Probabilistic Trading Strategy on the Nifty 50

October 14, 2026 · Chrisler Nunes

Strategy equity (teal, left axis) and the Nifty 50 index level (amber, right axis), July 1, 2024 to October 12, 2026. The axes have different scales, so compare the shapes of the lines, not their heights.

Introduction

In this project I trained a transformer binary classifier to predict the next day's direction for each of the 50 Nifty 50 stocks, and traded the predictions with a stop-loss, a take-profit and a time exit. Deep learning architectures built for language can be adapted to financial time series, and this post tests whether that adds up to a tradeable strategy on Indian large caps.

Each stock gets its own model, and the portfolio is the sum of the stocks' independent trade results. The models train on data from January 2020 to June 2024 and are tested out of sample from July 2024 to October 2026 against the Nifty 50 index.

Model Architecture

The model reads 20-day sequences of four daily features:

  • Log price return
  • Momentum, the close minus its 5-day moving average
  • RSI (14-day)
  • MACD difference (MACD line minus its signal line)

The network is:

  • A linear embedding from 4 features to 32 dimensions
  • Two transformer encoder layers with 4 attention heads
  • The 20 × 32 encoder output flattened into a dense layer of 64 units with ReLU
  • A sigmoid output: the probability that the next close is higher

It trains with binary cross-entropy and Adam (learning rate 0.001) for 20 epochs, without shuffling. Training uses data before July 1, 2024 (from January 2020). Everything from that date on is held out for testing.

Trading Strategy Implementation

A buy signal needs the model's probability above 0.5 and RSI above 50 and MACD difference above zero. Each position is managed with fixed rules:

  • 4% take-profit
  • 2% stop-loss
  • Exit after at most 5 trading days
  • A fixed ₹10,000 per trade, with no compounding

Each stock is an independent sleeve of ₹100,000. The portfolio curve is the sum of the sleeves, so 49 stocks make ₹49 lakh of capital. The benchmark is the Nifty 50 index (^NSEI) bought on the first test day and held, scaled to the same capital. Stocks with fewer than 300 training sequences before the test start (recent listings) are skipped; one stock was.

Design notes: the split is by date rather than a percentage, so the test covers more than two years. Profit and loss is booked on the exit date so the curve lines up with the index. The probability threshold is fixed at 0.5. A trade opens two trading days after the last day the model saw, which is one day after the move it predicted, and I have left that as is.

Model, sequences and features

class TransformerBinaryClassifier(nn.Module):
    def __init__(self, input_dim, seq_len, d_model=32, nhead=4, num_layers=2):
        super().__init__()
        self.embedding = nn.Linear(input_dim, d_model)
        encoder_layer = nn.TransformerEncoderLayer(d_model=d_model, nhead=nhead, batch_first=True)
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)
        self.fc_out = nn.Sequential(
            nn.Linear(d_model * seq_len, 64), nn.ReLU(),
            nn.Linear(64, 1), nn.Sigmoid()
        )

    def forward(self, x):
        x = self.embedding(x)
        x = self.transformer(x)
        return self.fc_out(x.reshape(x.size(0), -1))


class StockDataset(Dataset):
    def __init__(self, X, y):
        self.X = torch.tensor(X, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.float32).reshape(-1, 1)

    def __len__(self): return len(self.X)
    def __getitem__(self, idx): return self.X[idx], self.y[idx]


def create_sequences(X, y, seq_len):
    Xs, ys = [], []
    for i in range(len(X) - seq_len):
        Xs.append(X[i:i + seq_len])
        ys.append(y[i + seq_len])
    return np.array(Xs), np.array(ys)


def load_close(ticker):
    df = yf.download(ticker, start=START_DATE, end=END_DATE, progress=False)
    if isinstance(df.columns, pd.MultiIndex):          # flatten multi-level columns
        df.columns = [col[0] for col in df.columns]
    return df


def build_features(df):
    df = df.copy()
    df["Return"] = np.log(df["Close"] / df["Close"].shift(1))
    df["Momentum"] = df["Close"] - df["Close"].rolling(window=5).mean()
    df["RSI"] = ta.momentum.RSIIndicator(close=df["Close"], window=14).rsi()
    df["MACD_diff"] = ta.trend.MACD(close=df["Close"]).macd_diff()
    return df.dropna()

Risk-managed backtest and metrics

# ===================== BACKTEST =====================
def run_backtest(ticker, dates, close_prices, entry_signal):
    """
    Signal i buys close_prices[i+1]; then for j=1..5 the close close_prices[i+j+1] is checked for
    take-profit (+4%) / stop-loss (-2%), otherwise the position exits at the day-5 close.
    TP/SL fill exactly at the threshold. The last signal is skipped (no later prices).
    PnL is booked on the EXIT date so the equity curve has a real date axis.
    """
    trades = []
    n = len(close_prices)
    for i in range(len(entry_signal) - 1):
        if not entry_signal[i]:
            continue
        buy_price = close_prices[i + 1]
        entry_date = dates[i + 1]
        exit_idx, pct, reason = None, None, None
        for j in range(1, MAX_HOLD + 1):
            if i + j + 1 >= n:                          # ran out of data: close at last price
                exit_idx = n - 1
                pct = (close_prices[-1] - buy_price) / buy_price
                reason = "END"
                break
            chg = (close_prices[i + j + 1] - buy_price) / buy_price
            if chg >= TP_PCT:
                exit_idx, pct, reason = i + j + 1, TP_PCT, "TP"
                break
            elif chg <= SL_PCT:
                exit_idx, pct, reason = i + j + 1, SL_PCT, "SL"
                break
        if exit_idx is None:                            # no TP/SL in 5 days: exit at day-5 close
            exit_idx = i + MAX_HOLD + 1
            pct = (close_prices[exit_idx] - buy_price) / buy_price
            reason = "TIME"
        trades.append({
            "ticker": ticker, "signal_date": dates[i], "entry_date": entry_date,
            "exit_date": dates[exit_idx], "entry_px": buy_price,
            "exit_px": close_prices[exit_idx], "pct": round(float(pct), 4),
            "pnl": round(float(POSITION_SIZE * pct), 2), "reason": reason,
        })
    return trades


def sleeve_equity(dates, trades):
    """INITIAL_CASH plus cumulative realised PnL by exit date, on the stock's test dates."""
    pnl = pd.Series(0.0, index=pd.DatetimeIndex(dates))
    for t in trades:
        pnl.loc[t["exit_date"]] += t["pnl"]
    return INITIAL_CASH + pnl.cumsum()


def perf_stats(curve):
    r = curve.pct_change().dropna()
    yrs = max((len(curve) - 1) / 252, 1e-9)
    tot = (curve.iloc[-1] / curve.iloc[0] - 1) * 100
    cagr = ((curve.iloc[-1] / curve.iloc[0]) ** (1 / yrs) - 1) * 100
    sharpe = (r.mean() / r.std() * np.sqrt(252)) if r.std() > 0 else 0.0
    dd = (curve - curve.cummax()) / curve.cummax() * 100
    return tot, cagr, sharpe, abs(dd.min()), dd

Analysis and Insights

1. The strategy beat the index by 9.7 percentage points. It finished at ₹50.14 lakh from ₹49 lakh, while the Nifty 50 fell 7.4% over the same period. Its worst peak-to-trough fall was 0.73%, against 15.77% for the index.

2. Most of that gap comes from being mostly in cash. Each trade uses 10% of a stock's sleeve and positions last at most five days, so I estimate the strategy was only around 5–10% invested on average. The index was fully invested through a 15.8% drawdown. The small drawdown and the 1.46 Sharpe reflect low exposure at least as much as prediction skill.

3. The edge per trade is thin. The win rate was 45.5%, which works with a 4% take-profit and 2% stop-loss. Total profit of about ₹1.14 lakh over 7,274 trades is roughly 0.16% per trade before any costs. Delivery-based equity trades in India carry securities transaction tax on both the buy and the sell (0.1% each at last check), plus brokerage and slippage, so costs could consume most or all of that.

4. Two years is a better test than a few months, but it is still one stretch of market history. The index fell during this window, which favours a strategy that is mostly in cash. A rising window would likely show the opposite.

5. I have not yet checked whether the models predict anything. The script saves each stock's test accuracy and AUC in signal_summary.csv. If those sit near 0.5, the profit comes from drift and the exit rules, not from the transformer.

Future Enhancements

  • Transaction costs: add brokerage, taxes and slippage to see whether the edge survives.
  • Mark-to-market equity: value open positions daily instead of booking profit only at exit.
  • Exposure-matched benchmark: compare against an index position scaled to the strategy's average exposure.
  • Walk-forward retraining: retrain on a rolling window instead of once.
  • Entry timing: test entering on the day after the last input day, which is the day the model predicts.

Conclusion

On the Nifty 50, tested from a fixed split date, the strategy made a small gross profit while the index fell, with very small drawdowns. The result is encouraging but not yet evidence of a tradeable edge: exposure was low, the gross profit per trade is small, costs are not included, and the test window is short. The next steps are costs, an exposure-matched benchmark and the per-stock accuracy check.

This is research, not investment advice. Backtested results do not predict future returns.
